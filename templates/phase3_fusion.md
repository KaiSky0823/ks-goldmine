# 阶段 3 · 融合发散 → 合并 → 评委 → 红队 → 反方（第一批并行 agent）；主线程拟 Top N；补红队 → 工时压力测试（第二批）

每个 agent 输出到 `{OUT}/04_融合创意/<output_layout 里的文件名>.md`，断点续做同资产卡（末尾 <!-- DONE -->）。红线清单用 SKILL「判据速查·红线常客」，主线程粘贴进每个 prompt。

## 3.1 发散员（8 个视角各一个 agent，Opus xhigh，互不可见——不许读同目录其他人的文件）
视角：L1 人脉优先｜L2 现成资产最短路径（找「只差半天动作」的）｜L3 能力产品化（固定范围固定价、AI 与外包做 80%）｜L4 出海/美元（正视零受众与语言现实）｜L5 圈层/线下（一对多高客单，诚实面对潜水现实）｜L6 脑洞/非共识（把最不相干的资产硬接在一起，仍须写清谁付钱付多少）｜L7 复利/资产型（现金流腿→复利腿的衔接）｜**L8 擅长 × 兴趣（只从画像第 13 节的交集出发，找「眼前一亮」的组合：别人没做过、或别人做过但没人把这两样放在一起；每条仍必须写清谁付钱、付多少、第几天报价——创意是加分项，商业回报是门槛）**。
每人 8 个点子，每个必须融合 ≥2 个资产原子，写清：卖给谁（若有 1b，对应匿名清单里某类人）、交付什么、定价（项目制/月费制，折算时薪 ≥ 底价）、**替代品价格（现成软件/平台自带功能每月多少钱能做到八成；答不出就写「未查」，合并员据此降级）**、为什么是他、杠杆、前 14 天逐步动作（第几天把报价发给真人）、第 3 个月保守/中性月收入（写算式）、12 个月天花板、风险与法律旗标、证据引用。至少 3 个能 14 天内发出报价。数字宁低勿高。
主线程自己也先写一份种子创意，地位与发散员相同。

## 3.2 合并员（1 个，Opus xhigh）
读全部发散稿 + 主线程种子，合并去重为 ≤20 个候选（C01…）；同质点子合并保留最具体的客户/定价/14 天动作，收入取更保守的；踩红线（SKILL 红线常客）或依赖「先有粉丝/先有大额资金」的丢弃并写原因；**替代品价格为免费或平台自带功能就能做到八成、或填「未查」的，降为 option_bet 并标注红队 demand 必查**；给每个候选分类 fast_cash / compounding / option_bet / ritual；标 synergy_with。脑洞级只要「谁付钱、付多少、怎么起步」说得清就保留。

## 3.3 评委（3 个立场不同的 agent，Opus xhigh，各自独立）
J1 投资人式怀疑者（只信证据与基准率）｜J2 自负盈亏的一人公司（现金回笼速度、会不会吃爆工时、回款、复用）｜J3 一线销售（这句话发给人脉里那位老板他会不会回、起步价敢不敢当场买、一个从没开口收过钱的人会卡在哪）。
8 项 1–10 分：speed（≤8 周见钱）、hit_target（第 3–4 个月达标）、ceiling、unfair_advantage、leverage（收入脱离小时数）、safety、forcing_function（能否 14 天内逼他向真人报价）、**delight（眼前一亮：是否把他的擅长与兴趣结合成别人给不出的东西；只在该候选前七项三位评委均值都 ≥5 时计入，否则记 0、不重新归一——不许用它抬一个没人付钱的点子）**。评委按固定 JSON 返回：{judge, scores:[{cid, 8 项分, comment}], portfolio:[cid×3], portfolio_reason}。分数拉开差距，每候选一句最担心的点，最后各给一个三件套。
权重建议：speed .18 / hit .18 / ceiling .10 / unfair .14 / leverage .10 / safety .10 / forcing .12 / delight .08。

## 3.4 红队（前 6–8 名 × 三路，需求/成交用 Sonnet xhigh，法律用 Opus xhigh）
demand【需求真伪】：尽力证伪「真有人为这个按这个价付钱」；同类真实报价、成交与差评、替代品（免费工具、平台自带功能）；对照匿名清单到底有几个人对得上；「嘴上感兴趣」≠「已在为替代方案花钱」。
sales-ops【成交与交付现实】：按机主真实工时、行为短板、名单规模算漏斗每步转化；交付会不会吃爆时间；回款、范围蔓延、对伙伴/外包的依赖；给现实的第 3 个月保守收入及算式。
legal-ip【法律/合规/IP】：逐条查个人信息保护、平台条款、备案适用性、广告法与效果承诺、名誉权、版权与开源许可、资质边界（征信/涉外调查/医疗器械/投顾）、跨境收款税务、共有 IP、主体状态、发票个税；区分「致命」「改设计可规避」「合同写清即可」。
每路返回 verdict（survive / survive_with_changes / kill）、fatal_flaws、required_changes、evidence、adjusted_month3_conservative（含算式）、confidence。拿不准往不利方向判；证据确实强就承认并指出怎么改能活。

## 3.5 反方首席（红队之后、主线程拟 Top N 之前，1 个 agent，Opus xhigh）
challenger：读全部评委与红队文件，给出你认为最优的三件套并用五判据（14 天逼出报价 / 8 周见钱 / 第 3–6 月达标 / 不踩红线 / 不把小井打干）论证；主线程拿评委、红队、反方三份意见再拟 Top N。**拟入 Top N 的候选若不在已红队名单里，先补三路红队再定稿。**

## 3.6 工时压力测试（Top N 全部过了红队之后，1 个 agent，Opus xhigh）
hours-stress【工时与现金流压力测试】：把拟定组合排成 12 周逐周日历（每周 N 小时，另给 1.5N 对照版），逐项列前置/销售/澄清/交付/验收/开票/伙伴沟通各占多少小时，标出哪一周会爆、爆了砍什么；现金到账时间线（预付款/验收后付/账期/主体修复周期）；第 1/2/3/6 个月保守与中性收入（写算式）；三个概率区间（8 周内第一笔钱、第 3 个月达标、第 6 个月达标）及推导假设。只引红队修正值，不另起乐观口径。
