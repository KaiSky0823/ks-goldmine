# 阶段 4 · 报告结构 + 三位审查员

## 报告结构（正本由分片 cat 而成；改内容改分片再重拼）
一、一页纸结论（能独立阅读）：三句直话（含达标概率与「第一笔钱」概率）→ 一句肯定他真正稀缺的能力 → Top N 表（路径/对应候选/卖什么/价格与收款/第一张报价单/在 12 周里的角色）→ 开工前必办 D0 表（编号/做什么/怎么做/多久谁做，每行一句）→ 两条规矩（时间；过程指标代替金额指标）→ 这周要做的事（每条带宾语与入口）→ 需要拍板的事 → 我要更正的地方 → 未覆盖渠道一句指路。
二、为什么是这条路（证据链）：你这个人 / 你的人脉（分档口径先解释）/ 外部市场 / 筛选过程。
三、Top N 逐条：同一套小标题（卖什么/卖给谁/价格与收款/为什么是你/杠杆与工时上限/第 3 个月收入/12 个月天花板/红队必改项/放弃条件）。
四、12 周路线图、工时与现金（逐段安排、工时去向、收入与概率表、达标路径）。
五、没选的路径与原因（含「你提过的 X 为什么不在 Top N」「脑洞去哪了」「现成产品的去向」）。
六、红线清单（绝不做 / 每单都要做 / 自己的历史尾巴）。
附录：A 评分表与 B 红队裁决表（`scripts/score_table.py` 生成）｜B2 补红队｜B3 反方首席与工时压力测试员的数字与算式｜C 外部赛道一览｜D 时间去向｜E 武器库清单（已用/未用及原因）｜F 文件索引｜G 可直接用的模板（一页纸、那句话、不做清单、合同要点）。
口径写在最前：币种、流水/到手、每周几小时；内部编号首次出现要解释。

## 三位审查员（Opus，各写各的文件，只读不改报告）
R1 数字与证据核对员：每个数字/日期/排名/引语回溯源文件（grep 定位），算术复算，找内部前后矛盾、推断写成事实、口径混用（流水 vs 到手、8h vs 12h、币种）、比源文件更乐观处。只报有问题的与无法核实的。
R2 法律隐私与过度承诺审查员：每条行动建议本身是否合法、会不会把他带进风险；法规表述是否准确（可 WebSearch 核原文，拿不准标「需律师/会计确认」）；正文有无可识别第三方自然人；收入/概率/时间有无比红队与组合审查员更乐观；反向也查——有无为显得谨慎把不违法的事写成红线。
R3 读者视角审查员：对照原始委托找遗漏；找同一件事讲了几遍；未解释的缩写与内部代号；「这周要做的事」是否每条能直接动手；语气是否居高临下或为黑而黑、是否足够肯定做得好的部分；一页纸能否独立阅读。给到「位置 → 改成什么」。
三位审查员各写 `{OUT}/05_报告/_review_R1–R3.md`。主线程逐条处理 must_fix / should_fix，重拼，出 PDF，写「我要更正的地方」。二、你这个人 加「擅长 N 条 / 兴趣 N 条 / 交集 → 对应候选编号」；第五章加「L8 交集点子去哪了」。
