# ks-goldmine · 本机金矿挖掘 ⛏️

> *Mine your own machine: find what you're actually good at, what you actually care about, and where the two overlap into money.*

你电脑里有几十个项目、几百份笔记、几千条聊天。**你是这个星球上最了解这些东西的人，也是最看不见它们值多少钱的人。** 因为你天天看，早就麻了。

这个 skill 让 AI 用一个陌生人的眼睛，把你的硬盘从头到尾翻一遍，然后告诉你：你该向谁、按什么价、卖什么。

## 🗺️ 六个阶段

0. 🎯 **定约束** —— 目标金额与期限、每周几小时、本金、收款主体、红线。不问「你兴趣是什么」，问出来的不可信
1. 🔍 **只读盘点** —— 15～25 个范围各派一个 agent 出资产卡；最后一个 agent 出**机主画像**：擅长点（可多个，带证据）、兴趣点（可多个，从「反复投入却没人要求」的事里找）、二者交叉表
2. 🤝 **人脉线索**（可选，须授权）—— 本地统计你的聊天导出，数清楚**暖决策者到底有几个、谁亲口说过需求**
3. 🌐 **外部赛道证据** —— 价格基准、真实收入案例分级、失败模式、合规；每篇末尾「未用渠道及原因」
4. 💡 **融合 → 评委 → 红队** —— 8 个视角发散、3 个立场不同的评委打分、三路红队（需求 / 成交 / 法律）、一位反方首席、一位工时压力测试员
5. 📄 **Top N 报告 → 三审 → PDF → Top 1 交付包** —— 报价单、行业包、交付手册、首发名单开场白，你只差一个动作：把报价发出去

## 🧊 它冷酷的地方

- 收入只写**保守档**，附概率和算式
- 路径第一判据：**能否在 14 天内逼你把一张带金额的报价单发给一个真实的人**。「先做 demo 再报价」的路径一律降权
- 几条路径的收入相加前，先查它们是不是在抢同一份工时和名单
- 有一节叫「我要更正的地方」——AI 自己引入的乐观偏差，自己列出来

## 📖 来历

2026 年 9 月一次完整实跑：5 批并行 agent、130+ 个 agent、约 3,000 万 token，从一台用了多年的 Mac 里挖出一条「¥3,800 启动包 → ¥6,800 一周一个活 → 月费」的阶梯，以及一份 27 个暖决策者的首发名单。方法、模板、脚本、教训全在仓库里。

## 🔒 隐私

全程只读；不打开任何凭据文件；第三方姓名只留在本机线索文件，报告里一律角色化；聊天导出必须你明确授权，且只分析你本人的账号。

## 🧩 宿主

通用版。SKILL.md 开头的「宿主适配」表告诉你在 Claude Code / Codex / 其他助手里各对应什么。

## ⚙️ 安装

```bash
# Claude Code
git clone https://github.com/KaiSky0823/ks-goldmine.git ~/.claude/skills/ks-goldmine
# Codex
git clone https://github.com/KaiSky0823/ks-goldmine.git ~/.agents/skills/ks-goldmine
```

然后说一句：「挖我电脑里能赚钱的东西，3 个月内合法月入 ≥X，每周只有 Y 小时。」它会先告诉你这次要烧多少 token，让你选标准档还是轻量档。
